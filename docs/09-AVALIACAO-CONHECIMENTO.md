# Avaliação sintética

O conjunto desta fase usa apenas textos sintéticos marcados como fixture:
termos exatos, paráfrases, filtros, consulta sem resposta, versão antiga,
fonte rejeitada e texto com prompt injection. Mediremos recall@k, MRR,
precisão de filtros, exclusão de rejeitadas, rastreabilidade, latência e
consumo. Resultados não representam qualidade jurídica; nenhuma fonte real foi
ingerida.
